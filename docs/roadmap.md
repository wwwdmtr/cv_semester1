## Ближайшая задача V1

1. Визуализировать минимум два повтора каждого из пяти ID.
2. Сверить ID 2–5 с ошибками до выдачи человеку названий.
3. Уточнить доступность исходных EC3D-видео: в просмотренной папке найдены два pickle-файла, отдельные RGB-файлы не найдены.
4. Если исходные видео недоступны, выбрать небольшой демонстрационный набор с правом использования и зафиксировать происхождение. Собственные видео подходят для демонстрации; экспертные целевые метки нельзя заменять правилами из той же модели.
5. При отсутствии видео к концу второго дня зафиксировать сокращённый результат: проверенный классификатор скелетов и исследование устойчивости. Не называть его проверенной системой оценки обычного видео.
