# Оценка двух ошибок приседания по многоракурсной 3D-позе: рабочий черновик статьи

**Статус:** рабочий черновик, дополненный результатами до 14.11.2026. Текст ещё не предназначен для отправки в журнал. Перед публикацией нужны независимые участники или согласованный внешний набор, проверка исходных RGB-видео и уточнение ближайших аналогов. Полная история опытов и предварительные протоколы — в [едином дневнике](../experiments/README.md).

## Аннотация

В работе исследуется автоматическая оценка двух признаков техники приседания: сведения коленей внутрь и недостаточной глубины. Используется поднабор REHAB26-ViewAngles из 388 физических повторений пяти людей, каждый из которых записан тремя синхронными камерами. Входом служат готовые последовательности MediaPipe world-поз, а параметры модели выбираются на внутренних разбиениях без тестового человека. Исходный классификатор получил средний по отложенным людям Macro-F1 0,672, ошибочно критиковал 21,1% корректных повторений и обнаружил 74,2% ошибочных. Описательное усреднение оценок трёх камер повысило Macro-F1 до 0,749 и снизило долю ложных замечаний до 14,9%, однако требует синхронной многоракурсной записи и пока не подтверждено независимо. Гипотеза о том, что visibility нужных суставов в информативной фазе лучше обычной уверенности указывает на ошибочное замечание, не подтвердилась: AUROC составил 0,500 против 0,756 у уверенности. Временная CNN превзошла перемешанный контроль, однако ни она, ни её фиксированная смесь с геометрическим классификатором не улучшили baseline. Полученные результаты показывают чувствительность оценки техники к человеку и ракурсу и не позволяют рекомендовать систему для автоматической обратной связи без дополнительной проверки.

## 1. Введение

Автоматическая оценка техники упражнений должна не только распознавать ошибку, но и избегать уверенных неверных замечаний. Эта проблема особенно важна при смене человека и ракурса: одинаковое движение может давать разные наблюдения суставов. В данной работе задача намеренно сужена до одного упражнения и двух признаков, которые присутствуют в разметке выбранного набора.

Исследовательский вопрос формулируется так: **можно ли на новых людях надёжно распознавать сведение коленей и недостаточную глубину, а доступность нужных суставов использовать для отказа от сомнительного замечания?**

Работа проверяет три практических аспекта:

1. честный baseline на разбиениях по людям;
2. согласованность ответов между синхронными камерами и описательное объединение ракурсов;
3. способность уверенности и visibility отделять ошибочные ответы модели.

## 2. Данные и постановка задачи

Основной набор — REHAB26-ViewAngles. В выбранный поднабор входят 388 физических повторений: 276 корректных по протоколу набора, 56 со сведением коленей и 56 с недостаточной глубиной. Три камеры дают 1 164 наблюдения, но не увеличивают число независимых движений или участников. В исследовании пять людей.

Одна входная запись — заранее выделенное повторение в формате `(кадры, 33 сустава, x/y/z/visibility)`. Исходное RGB-видео в текущем эксперименте не используется. Поэтому работа оценивает классификацию по готовой позе, а не полный путь «произвольное видео → поза → замечание».

Три целевых класса:

- корректно в пределах выбранных двух критериев;
- колени внутрь;
- малая глубина.

Другие ошибки REHAB26 не превращаются в корректные примеры и исключаются из трёхклассовой оценки. Повторы с дополнительными ошибками не получают искусственно упрощённую метку.

## 3. Метод

### 3.1. Протокол проверки

Используется внешнее leave-one-person-out разбиение: один человек полностью остаётся для теста, включая все его камеры. Подбор семейства модели и параметров выполняется только на внутренних разбиениях остальных людей. Все наблюдения одного физического повторения находятся в одной части данных.

Основная метрика — средний по пяти тестовым людям Macro-F1. Дополнительно измеряются:

- доля корректных повторений с ошибочным замечанием;
- доля ошибочных повторений, для которых замечена любая ошибка;
- доля ошибок с правильно определённым типом;
- результаты отдельно по людям и камерам.

Инженерские ориентиры были зафиксированы как не более 20% ложных замечаний и не менее 80% обнаруженных ошибок. Это критерии первой полезной версии, а не заявленный медицинский норматив.

### 3.2. Исходная модель

Сравнивались логистическая регрессия, SVM и ансамбль деревьев на 35 геометрических признаках: пяти квантилях семи сигналов полного повторения. Эти признаки не сохраняют порядок кадров. Автоматическая внутренняя процедура выбрала логистическую регрессию во всех пяти внешних разбиениях. В репозитории сохранены внешние предсказания, модели разбиений, модель на всех доступных людях и параметры запуска.

### 3.3. Дополнительные проверки

После baseline были выполнены четыре ограниченных опыта:

1. усреднение векторов `class_scores` трёх синхронных камер одного повтора;
2. прямые и двухступенчатые модели на объединённых 2D-признаках синхронных `cam1` и `cam3` одного физического повтора; предположение о постоянных фронтальном и профильном видах ограничено тем, что участник меняет ориентацию;
3. безопасные train-only аугментации: зеркало и временная интерполяция 0,85×/1,15×;
4. отказ по уверенности, общей visibility, visibility нужных суставов в нижней фазе и минимальной visibility.

Многоракурсное объединение было выбрано после просмотра baseline и поэтому считается описательным результатом. Оно не заменяет независимую проверку заранее зафиксированного метода.

## 4. Результаты

### 4.1. Сравнение вариантов

| Вариант | Единица оценки | Macro-F1 | Ложные замечания | Обнаружение ошибок | Верный тип ошибки |
|---|---|---:|---:|---:|---:|
| Исходный классификатор | отдельная камера | 0,672 | 21,1% | 74,2% | 67,9% |
| Среднее трёх камер | физический повтор | 0,749 | 14,9% | 75,3% | 74,4% |
| Прямые 2D-признаки двух камер | физический повтор, cam1 + cam3 | 0,709 | 31,0% | 82,3% | — |
| Двухступенчатые 2D-признаки двух камер | физический повтор, cam1 + cam3 | 0,635 | 37,7% | 80,6% | — |
| Зеркало + изменение темпа | отдельная камера | 0,654 | 20,8% | 71,3% | — |

Усреднение трёх камер дало лучший общий компромисс, но сравнивает один физический повтор с тремя отдельными наблюдениями baseline и требует специальной записи. Прямые двухкамерные 2D-признаки повысили обнаружение ошибок ценой резкого роста ложных замечаний; это не чистое сравнение однокамерных 2D и 3D, поскольку различаются число входных камер и признаки. Аугментации не улучшили основной результат. Эти варианты отклонены для финального однокамерного pipeline.

### 4.2. Разброс по людям

Для многоракурсного варианта Macro-F1 изменялся от 0,525 до 0,943. У Honza доля ложных замечаний составила 49,1%, а у Vasil было обнаружено только 26,1% ошибочных повторений. Среднее улучшение поэтому не означает одинаковой надёжности для нового человека.

### 4.3. Проверка надёжности

| Сигнал риска | AUROC всех ошибочных ответов | AUROC ошибочных корректирующих замечаний |
|---|---:|---:|
| Низкая уверенность классификатора | 0,670 | 0,756 |
| Низкая общая visibility | 0,442 | 0,448 |
| Низкая visibility нужной фазы | 0,477 | 0,500 |
| Низкая минимальная visibility | 0,453 | 0,462 |

Visibility не превзошла уверенность. В описательной проверке с сохранением 80% ответов по рангу уверенности ложные замечания уменьшились до 14,5%, но обнаружение ошибок среди всех ошибочных повторений снизилось до 61,0%. Следовательно, отказ не выполнил одновременно оба инженерных ориентира. Такой ранговый отбор не задаёт готового порога для применения: порог отказа на обучающих или валидационных данных здесь не определялся.

### 4.4. Дополнительные опыты с фазами и временной CNN, 14.11

Добавление семи разностей геометрии нижней фазы и начала/конца повтора к исходным 35 признакам повысило средний Macro-F1 до 0,687, но улучшение было только у двух из пяти людей и не достигло заданного порога +0,02. [Протокол и результат 35D/42D](../experiments/runs/20261114-010658_rehab26_phase_relative42_v1_caa50190/reports/README.md).

Последние два опыта проверили пользу временной структуры и дополнение геометрии. Семь исходных сигналов интерполировали в 64 точки нормированного времени. CNN состояла из двух Conv1d шириной 5 с 16 выходными каналами, ReLU, усреднения в четыре временных блока и линейного классификатора; 2 067 параметров на инициализацию. Нормализация обучалась только по train. Каждый кандидат обучался 120 эпох full-batch Adam (learning rate 0,01, weight decay 0,001); ответ — среднее вероятностей трёх seed {0,1,2}. Это 1D-сеть над готовой геометрией, без обучения извлечения поз из RGB.

Контрольная CNN получала те же значения после отдельной фиксированной перестановки времени каждого физического повтора, общей для семи каналов и трёх камер. Перемешивались train и test. Единственный сетевой гиперпараметр, балансировка классов, выбирался общим для двух условий по симметричной внутренней оценке. Второй опыт использовал заранее фиксированное среднее вероятностей геометрического классификатора и ordered CNN 50/50, без подбора веса.

| Условие | Средний Macro-F1 по людям | Ложные замечания | Обнаружение ошибок | Худший F1 человека |
|---|---:|---:|---:|---:|
| Исходная геометрия 35D | 0,672 | 21,1% | 74,2% | 0,554 |
| CNN, исходный порядок | 0,615 | 30,0% | 74,8% | 0,386 |
| Та же CNN, перемешанное время | 0,573 | 36,3% | 73,1% | 0,433 |
| Геометрия + ordered CNN, 50/50 | 0,666 | 23,7% | 74,5% | 0,451 |

Общий критерий относительно baseline требовал прироста среднего Macro-F1 не менее 0,02, ухудшения FPR и error recall не более 2 п.п. и роста F1 минимум у трёх из пяти людей. Для гипотезы о порядке дополнительно требовалось преимущество над shuffled-контролем не менее 0,01 с ростом минимум у трёх людей; для гипотезы о дополнении — такое же преимущество смеси над отдельной CNN.

Оба полных критерия не выполнены. Ordered CNN превысила shuffled по среднему F1 на 0,0415 и у 3/5 людей, но уступила геометрии на 0,0573 при росте ложных замечаний на 8,92 п.п. Смесь улучшила отдельную CNN у всех людей, однако уступила геометрии на 0,0058 и повысила ложные замечания на 2,64 п.п. У Terka F1 снизился с 0,577 у геометрии до 0,386 у CNN; у Petra вырос с 0,770 до 0,836. Эти результаты поддерживают пользу сохранения временной структуры относительно выбранного контроля, но не превосходство данного временного метода или ансамбля над исходным представлением.

[Полный отчёт последних двух опытов](../experiments/runs/20261114-020933_rehab26_temporal_final_two_v1_e8796231/reports/README.md). Дополнительные многоракурсные переносы и все их отрицательные варианты приведены в [дневнике](../experiments/README.md); их нельзя смешивать с трёхкамерным усреднением при применении.

## 5. Обсуждение

Исходные опыты дают три основных наблюдения.

Во-первых, смена ракурса существенно влияет на ответ: хотя камеры показывают одно движение, у 42,3% физических повторений хотя бы две камеры дали разные классы. Во-вторых, синхронные ракурсы могут быть полезны как источник дополнительной информации, но такая конфигурация не соответствует обычному сценарию с одним телефоном. В-третьих, MediaPipe visibility в проверенных агрегациях не является надёжной мерой корректности итогового замечания.

Отрицательный результат важен для границ метода: простое добавление visibility не решает проблему надёжности. Более перспективными направлениями выглядят калибровка уверенности на внутренних данных, явная оценка качества позы по временным скачкам и независимая проверка на новых людях. Эти направления пока не являются результатом текущей работы.

## 6. Ограничения

- Только пять участников; камеры и искусственные варианты не заменяют новых людей.
- Использованы готовые MediaPipe world-позы, а не полный RGB-pipeline.
- Точная визуальная корректность границ повторений без RGB не подтверждена.
- Метки набора принимаются как целевые; повторная независимая экспертная разметка не проводилась.
- Уверенность классификатора не откалибрована как вероятность правильности.
- Многоракурсное объединение исследовано после просмотра baseline и требует независимого подтверждения.
- Дополнительные гипотезы выбраны после просмотра прежних результатов на тех же пяти людях. Хотя рецепты и критерии фиксировались до новых запусков, выводы остаются исследовательскими, без независимого подтверждения или заявления статистической значимости.
- Результаты относятся только к двум выбранным ошибкам приседания и не означают полной проверки техники.
- Ни один вариант не достиг целевых ограничений для каждого участника; автоматические рекомендации пока не разрешаются.

## 7. Вывод

Построен воспроизводимый baseline оценки двух ошибок приседания на новых людях и проверены несколько способов улучшения и отказа. Лучший описательный результат получен при объединении трёх синхронных камер, однако однокамерная система остаётся ниже заданных ориентиров. Основная гипотеза о преимуществе фазовой visibility отклонена. Для сильного вывода необходимы новые участники или внешний согласованный набор, исходные видео и заранее зафиксированная повторная проверка.

После двух последних сравнений поиск моделей на этом наборе остановлен. Преимущество временного порядка относительно контроля не привело к улучшению baseline; смесь не превзошла оба компонента. Следующий этап — проверка полного пути на собственных видео. Неудача данного рецепта не доказывает бесполезность всех временных моделей, а возможные причины ухудшения переноса требуют отдельного исследования.

## 8. Материалы для воспроизведения

Основные команды:

```bash
python scripts/download_rehab26.py --dimensions 3d
python scripts/rehab26_baseline.py
python scripts/analyze_view_consistency.py
python scripts/analyze_multiview_fusion.py
python scripts/evaluate_view_specific_2d.py
python scripts/evaluate_safe_augmentations.py
python scripts/analyze_reliability.py
python scripts/build_rehab26_demo.py
python -m pip install -r requirements-temporal.txt
python scripts/run_phase_features.py
python scripts/run_temporal_comparison.py
python -m unittest discover -s tests -v
```

Исторические отчёты, внешние предсказания, настройки и рисунки находятся в `reports/`, новые запуски — в `experiments/runs/`; модели — в исключённом из Git каталоге `models/`. Сырые данные не публикуются в репозитории.

Контрольная проверка исходного pipeline включала два запуска с одинаковым `seed=0`. Все 6 984 строки внешних предсказаний двух запусков совпали. Для выбранной логистической регрессии 1 164 предсказанных класса и основные метрики совпали с сохранённым baseline. У отклонённого ансамбля деревьев изменились 6 из 1 164 классов; это отличие не используется как улучшение и отдельно зафиксировано в [контрольном отчёте](../reports/final_verification.md).

Для последних двух опытов сохранены 4 656 внешних предсказаний, двадцать моделей разбиений с проверкой после загрузки, внутренние поиски, кривые train-loss и протоколы до запуска. Исходные 1 164 класса baseline воспроизведены без изменений. Final refit не выполнялся; артефакты перечислены в [отчёте запусков CNN и фиксированной смеси](../experiments/runs/20261114-020933_rehab26_temporal_final_two_v1_e8796231/reports/README.md).
