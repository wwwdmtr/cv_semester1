## 2026-11-14 · запись 17 · протокол до обучения: последние две гипотезы о времени и дополнении геометрии

**Статус при записи:** реальные новые модели ещё не обучались. Пользователь разрешил ещё пару гипотез и сравнений; при неудаче поиск на текущем наборе прекращается, следующий этап — работа с собственными видео. Фиксируем ровно два вопроса и четыре условия. Не менять рецепт, эпохи, seed, пороги успеха и состав входа после просмотра внешних ответов. Успех также требует проверки на видео, а не запуска дополнительной цепочки подбора по тем же пяти людям.

**H17:** обучаемая временная структура семи геометрических сигналов повышает качество относительно глобальных квантилей; преимущество связано с порядком/соседством, а не только с другой нелинейной моделью. Контроль — такая же сеть с перемешанным временем и теми же значениями сигналов. Проверяется конкретная небольшая temporal CNN, не произвольная динамика, не GCN Zhao и не обучение извлечения поз из RGB.

**H18:** геометрический классификатор и временная сеть дают дополняющие ответы, поэтому заранее фиксированная смесь вероятностей 50/50 превосходит каждый компонент. Вес не подбирается ни на внутренней, ни на внешней проверке.

**Данные/разбиения:** прежние 388 физических повторов пяти людей / 1 164 наблюдения трёх камер, три класса, прежние фильтры. Внешний LOPO по пяти людям, внутри — LOPO по четырём train-людям. Все кадры/камеры/преобразования человека и физического повтора остаются вместе. Вес наблюдения — обратное число камер его физического повтора. Любая ошибка входа сохраняется и прерывает запуск; исключение строк и отказ от трудных наблюдений запрещены. Используется полный повтор, visibility не участвует.

**Четыре условия:**

1. `global35`: неизменённые исходные 35 признаков; логистическая регрессия, прежние C ∈ {0.1, 1, 10} × balanced ∈ {false, true}. Масштабирование, class weights и выбор только по внутренним train-людям. Проверить совпадение всех 1 164 классов с историческим `inner_selected`.
2. `temporal_ordered`: те же семь исходных сигналов `extract_signals`; каждый линейно интерполируется по нормированному времени [0,1] в 64 точки. Вход `(N,64,7)`, значение абсолютной длительности теряется. Обучаемая нормализация канала — weighted mean/std только текущего train по всем его кадрам; константные каналы получают масштаб 1. CNN: Conv1d(7,16,kernel=5,padding=2) → ReLU → Conv1d(16,16,kernel=5,padding=2) → ReLU → AdaptiveAvgPool1d(4) → Flatten → Linear(64,3). Используется train-only взвешенная cross-entropy, full-batch Adam, learning_rate=0.01, weight_decay=0.001, ровно 120 эпох без ранней остановки. CPU, один поток, детерминированные операции, float32 обучение. Единственный сетевой гиперпараметр — balanced false/true.
3. `temporal_shuffled`: тот же вход после интерполяции, затем одна фиксированная перестановка 64 индексов по стабильному hash(physical_id,seed=1729). Одна перестановка на физический повтор, одинаковая для трёх его камер и семи каналов; сохраняется для всех эпох. Это независимые перестановки разных повторов, а не одна глобально обратимая перестановка всего набора. И train, и test этой ветви перемешаны; это не только повреждение test. Архитектура, масштабирование, class weights, длительность обучения и seed совпадают с ordered.
4. `geometry_temporal_fusion`: `(p_global35 + p_temporal_ordered)/2` с порядком классов [0,1,2], затем argmax. Используются те же выбранные и обученные компоненты внешнего train; нового fit, stacker, порога и подбора веса нет.

**Seed и выбор CNN:** каждый CNN-кандидат — ансамбль трёх независимых инициализаций seed={0,1,2}; сначала среднее трёх softmax-векторов в float64, затем argmax и метрики. Не выбирать seed и не усреднять F1 вместо вероятностей. Для чистого контроля порядка выбирается **один общий balanced-флаг** двух ветвей: для каждого флага симметрично усреднить внутренние mean Macro-F1, FPR и error recall ordered/shuffled; выбрать по прежнему правилу `select_candidate` (приоритет guardrails FPR≤0.2 и recall≥0.8, затем F1, FPR, recall, стабильный ID). Обе внешние ветви обучаются с выбранным общим флагом. Baseline выбирается отдельно по прежнему правилу из своих шести кандидатов. Выбор сохраняется до внешних предсказаний.

**Метрики:** средние по пяти внешним людям Macro-F1, доля ложных замечаний среди корректных повторов, обнаружение любой ошибки, верный тип ошибки; дополнительно каждый человек/класс/камера/ракурс, худший человек и фактическое покрытие. Средние вероятности трёх seed не добавляют людей; std — по пяти людям. Пять уже просмотренных людей остаются исследовательской, не независимой подтверждающей выборкой.

**Критерии успеха до результата:**

- Общий практический критерий относительно `global35`: прирост среднего Macro-F1 ≥0.02, FPR увеличился не более чем на 2 п.п., error recall упал не более чем на 2 п.п., Macro-F1 вырос минимум у трёх из пяти людей.
- H17 подтверждена в рамках пилота, только если `temporal_ordered` выполнила общий критерий **и** превысила `temporal_shuffled` по среднему Macro-F1 минимум на 0.01 с ростом минимум у трёх из пяти людей. Отдельно показать оба сравнения, если полный критерий не выполнен.
- H18 подтверждена в рамках пилота, только если `geometry_temporal_fusion` выполнила общий критерий **и** превысила `temporal_ordered` по среднему Macro-F1 минимум на 0.01 с ростом минимум у трёх из пяти людей. Одного выигрыша над слабой сетью или baseline недостаточно для вывода о дополнении.
- Это инженерские критерии пилота, не тест статистической значимости и не установленная научная новизна. Исходные требования FPR≤0.2/recall≥0.8 показывать отдельно; относительное улучшение ещё не означает готовность приложения.

**Артефакты/проверки:** снимок исходников/библиотек до запуска, копия этого протокола и его SHA256, исходные/перемешанные матрицы и хеши с проверкой сохранения значений, внутренние предсказания всех кандидатов с участниками обучения, поиск/выбор до outer predict, внешние 4×1 164 предсказания с вероятностями, двадцать fold-bundle с провенансом и проверкой после загрузки, кривые train-loss трёх seed без последующего подбора эпох. Нет final refit, замены старой deployment-модели, GPU, новых видео или удаления неудачных ветвей. Библиотека для опыта: PyTorch 2.5.1, зависимости отдельно в `requirements-temporal.txt`; исходная геометрия работает без PyTorch. Команда: `.venv/bin/python -B scripts/run_temporal_comparison.py`.
