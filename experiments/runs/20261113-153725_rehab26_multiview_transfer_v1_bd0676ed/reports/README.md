# Первый пилот: несколько камер при обучении, одна при применении

Исследовательский опыт на 388 повторах пяти людей, 1 164 наблюдениях. На тесте модель получает только 35 геометрических признаков одной камеры; другие камеры и угол недоступны. Покрытие 100%. GPU не используется.

Протокол, записанный до обучения: [protocol_before_run.md](protocol_before_run.md). Все пять условий имеют одинаковую внутреннюю сетку student-параметров. Teacher targets и веса заново cross-fit только внутри каждого train subset.

## Заранее заданная проверка H1

Практический критерий не выполнен. Это решение данного пилота, не доказательство статистической значимости.

Conditional минус обычный перенос: Macro-F1 +0.0032; ложные замечания -3.15 п.п.; обнаружение ошибок -2.38 п.п. FPR уменьшился у 4 из 5 людей.

- `false_feedback_reduced_at_least_3pp`: да.
- `error_recall_loss_at_most_2pp`: нет.
- `macro_f1_not_reduced`: да.
- `false_feedback_reduced_in_at_least_3_people`: да.

Преимущество над плохим обычным переносом само по себе не означает улучшения проекта: нужны сравнения с supervised и обоими контролями. Все разности сохранены в [hypothesis_checks.json](hypothesis_checks.json).

## Ограничения и артефакты

Пять людей и прежние результаты уже просмотрены при выборе направления; опыт не является независимым подтверждением. Углы из разметки — дополнительная информация обучения. Веса класса/ракурса — proxy по ошибкам маленького teacher; они не измеряют физическую наблюдаемость. Поклассовая нормировка меняет массы классов; scalar gate не является точным matched-strength контролем. Пилот ограничен 35 глобальными признаками и фиксированным teacher. Разные камеры одного движения не являются независимыми людьми.
