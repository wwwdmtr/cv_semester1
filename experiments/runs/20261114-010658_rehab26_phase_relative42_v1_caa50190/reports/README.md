# R2: глобальные и относительные фазовые 3D-признаки

Два условия на одних 388 физических повторах пяти людей / 1 164 наблюдениях. Одна камера при применении, полное покрытие, без новых видео и GPU. Гиперпараметры выбирались только во внутренних разбиениях по людям.

[Протокол до обучения](protocol_before_run.md). Проверяется один заранее заданный набор дополнительных признаков; исходный pipeline и основная модель не заменяются автоматически.

## Границы вывода

Пять людей и прежние результаты уже просмотрены при выборе гипотезы. Признаки используют наблюдаемый полный повтор: lower-phase proxy по углам и первые/последние кадры, не экспертную разметку фаз. Это не модель, обучающая весь временной порядок: обратное воспроизведение того же повтора сохраняет симметричные края и такие признаки. Новые телефоны, одежда, RGB-путь, неполные повторы и перенос на независимых людей здесь не проверены. Файлы старых моделей и закрытых запусков сохранены.
