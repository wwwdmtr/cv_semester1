# Две последние гипотезы: временная CNN и дополнение геометрии

388 физических повторов пяти людей, три синхронные камеры, 1 164 наблюдения. Одна камера и полный повтор на входе. Полное покрытие; без новых видео. Все сравнения исследовательские на уже просмотренных пяти людях.

[Протокол до обучения](protocol_before_run.md). Один общий balanced-флаг двух CNN выбран симметрично только на внутренних людях. Каждая CNN — среднее вероятностей трёх seed, не выбор лучшей инициализации. Смесь геометрии и ordered CNN зафиксирована 50/50, без настройки веса.

## Решение и границы вывода

Поиск архитектур/признаков на этом наборе остановлен по согласованному бюджету. Следующий этап — работа с собственными видео и статья. При невыполненных критериях прежний baseline остаётся основой видеопроверки. Ни один вариант здесь не заменяет автоматически deployment-модель: сохранены только модели внешних разбиений.

Это небольшая 1D CNN над семью готовыми геометрическими сигналами. Она исследует локальные временные связи и грубую позицию фазы, не извлечение признаков из RGB и не воспроизведение GCN Zhao. Нормированное время не сохраняет абсолютную длительность. Перемешивание сохраняет значения, но разрушает соседство и фазовую позицию; его эффект не доказывает конкретную биомеханическую интерпретацию. Новые люди, телефонная камера, одежда, автоматические границы и полный RGB-путь не проверены. Неудача этого рецепта не доказывает бесполезность любых временных моделей.
