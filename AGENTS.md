# Продолжение проекта

Перед изменениями прочитай [передачу контекста в едином дневнике](experiments/README.md#handoff-current) и последующие записи. Дневник — источник текущих решений; старые планы не возобновляют завершённые задачи. История чата не требуется.

- Цель команды — закончить проект по компьютерному зрению и статью с проверяемой исследовательской работой. Общайся по-русски, объясняй методы простыми словами. Не обещай научную новизну или оценку преподавателя без оснований.
- Поиск моделей на текущих позах остановлен по решению пользователя. Следующий этап — собственные видео и существующий классификатор. Не запускай новое обучение, подбор архитектур или трансформеры по собственной инициативе. Новое поручение пользователя может изменить этот план.
- При работе с видео сначала проверь сохранённые веса и входной контракт из README/дневника. Готовые MediaPipe world-позы и нормированные координаты изображения не взаимозаменяемы. Результат на заранее выделенном полном повторе не доказывает работу на частичном приседе/потоке.
- Записывай новые важные решения в `experiments/README.md`. Не создавай второй дневник и не переписывай прошлые записи или протоколы после результата. В `docs/article-draft.md` находится текст статьи, а не альтернативный журнал решений.
- Закрытые `experiments/runs/` и `experiments/sources/` неизменяемы; проверяй их через `scripts/experiment_log.py verify`. Не удаляй отрицательные, прерванные и импортированные результаты ради чистоты. Не переобучай модель для проверки сохранности.
- Люди, кадры, камеры и аугментации одного движения не должны пересекать train/test. Обучаемая предобработка и выбор параметров используют только train. Пять людей не превращаются в большую независимую выборку после аугментаций; F1 не является вероятностью правильного ответа.
- Не смешивай историческую задачу EC3D с текущими классами REHAB26. Технические форматы, разметка и края данных описаны в [протоколе](docs/experiment-protocol.md); прошлые неопределённости не выдавай за устранённые.
- Данные, модели и `.venv` исключены из Git. На другом компьютере сначала установи, какие файлы действительно доступны; отсутствие весов в checkout не означает, что прежнее обучение не выполнялось. Перенос файлов описан в дневнике.
- Сохраняй изменения команды и общие заметки `docs/brainstorm.md`. Не заполняй за участников их личные карточки чтения и не заменяй историю обсуждений выводами агента.

Навигация и запуск — [README](README.md), формат архива — [инструкция журналирования](docs/experiment-log.md). Выполняй команды из корня этого репозитория. Для изменения только документации достаточно проверить ссылки, согласованность чисел и `git diff --check`; новое обучение не требуется.
