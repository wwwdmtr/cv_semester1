# Оценка техники приседаний по видео

Рабочая цель: по короткому видео одного приседания проверять два признака — сведение коленей внутрь и недостаточную глубину — и сообщать, когда данных для оценки недостаточно.

**Состояние на 05.11.2026:** основной набор — REHAB26-ViewAngles. Все 15 файлов 3D-поз приседаний скачаны и проверены; выполнено первое сравнение регрессии, SVM и ансамбля деревьев. Сохранены модели, предсказания и результаты проверки на новых людях. Срок проекта — 11.11, ресурсы — RTX 2060 6 ГБ или Colab; текущие модели обучаются на CPU. Гипотеза о полезности фазовой видимости и её новизна ещё не проверены.

## Что уже работает

**REHAB26:** 388 физических повторений пяти людей, три камеры каждого — 1 164 наблюдения. Три категории: корректно в протоколе набора / колени внутрь / малая глубина. Подбор параметров выполняется только на внутренних разбиениях по людям.

| Подход | Macro-F1 по новым людям | Ложные замечания | Обнаруженные ошибки |
|---|---:|---:|---:|
| Регрессия, исходные настройки | 0,662 ± 0,125 | 28,8% | 78,8% |
| Регрессия с подбором | 0,672 ± 0,095 | 21,1% | 74,2% |
| SVM с подбором | 0,446 ± 0,183 | 39,3% | 59,8% |
| Ансамбль деревьев с подбором | 0,499 ± 0,089 | 20,5% | 55,3% |

Автоматическая процедура выбора семейства по внутренним результатам выбрала регрессию во всех пяти внешних разбиениях. Ориентиры ≤20% ложных замечаний и ≥80% обнаруженных ошибок пока не достигнуты. Все ракурсы присутствовали у обучающих людей; это проверка нового человека, а не неизвестного диапазона углов. Пять людей ограничивают убедительность выводов. Подробности — в [отчёте](reports/rehab26_baseline/README.md).

Модель для дальнейшего использования: `models/rehab26_baseline/squat_geometry.joblib`. Она обучена на всех доступных людях и имеет отдельную пометку об отсутствии собственного независимого теста; метрики выше относятся к внешним разбиениям. Вход — одно заранее вырезанное повторение MediaPipe world-позы `(кадры,33,4)`, не RGB-видео. Отказы от оценки ещё не настроены.

## Исторический результат EC3D

Ниже — baseline пяти категорий на другом наборе. Прямое сравнение его чисел с REHAB26 некорректно.

Загрузка проверенной версии EC3D, сборка повторений из кадров, аудит и два обучаемых baseline. В эксперимент вошли **132 приседания четырёх участников**. Все кадры одного человека остаются в одной части данных.

| Подход | Macro-F1: правильно / ошибка | Macro-F1: пять меток |
|---|---:|---:|
| Постоянный ответ | 0,407 ± 0,010 | 0,095 ± 0,007 |
| Геометрия + логистическая регрессия | 0,786 ± 0,233 | 0,622 ± 0,035 |
| Координаты + логистическая регрессия | 0,622 ± 0,221 | 0,432 ± 0,169 |

Среднее и стандартное отклонение посчитаны по четырём тестовым участникам. Этот классификатор проверен **на подготовленных 3D-скелетах EC3D**. Его перенос между системами суставов ещё предстоит проверить; для REHAB26 обучены отдельные модели.

## Запуск

Python 3.10 или 3.11. Для этих baseline GPU не нужен. Команды выполняются из корня репозитория.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/download_rehab26.py
python scripts/rehab26_baseline.py
python -m unittest discover -s tests -v
```

В Colab используются те же команды после установки зависимостей. Загрузка получает только 3D-позы приседаний, проверяя размеры и CRC32 записей фиксированного архива; локальные SHA-256 сохраняются для воспроизводимости. Выгрузка всего RGB не нужна для этого baseline.

Исходные результаты остаются в `reports/rehab26_baseline/` и `reports/ec3d_baseline/` и дополнительно архивированы в журнале. Каждый новый запуск автоматически получает отдельную папку `experiments/runs/<имя>/`, снимок кода, лог, настройки, метрики и графики; модели — `models/experiments/<имя>/`. Непустые явно заданные каталоги не перезаписываются. Сводная таблица: [журнал](experiments/README.md); подробности: [инструкция](docs/experiment-log.md). Сырые данные, модели и `.venv/` исключены из Git. EC3D повторяется командами `python scripts/download_ec3d.py` и `python scripts/ec3d_baseline.py`.

## Применение REHAB26-модели

```bash
python scripts/predict_rehab26.py path/to/repetition.npy
```

Вход `(кадры,33,4)` соответствует сохранённой схеме MediaPipe world-позы. Значение score не является откалиброванной вероятностью правильности. Все 30 моделей проверочных разбиений и отдельная финальная модель сохранены вместе с предобработкой и проверены после загрузки. Автоматическая обработка произвольного RGB-видео ещё не проверена.

По умолчанию команда использует исходную сохранённую модель. Для модели нового опыта укажите `--model <путь из run.json>/squat_geometry.joblib`; новые запуски не подменяют этот файл автоматически.

## Сохранённые исторические модели EC3D

С 05.11.2026 скрипт сохраняет обученные классификаторы вместе с масштабированием признаков и описанием входных данных в `models/ec3d_baseline/`:

- `squat_geometry.joblib` — классификатор пяти категорий на геометрических признаках, обученный на всех 132 примерах для дальнейшего использования.
- `squat_binary.joblib` — аналогичная модель «корректно / ошибка».
- `folds/` — модели каждого проверочного разбиения с участниками обучения и порогом отказа, выбранным на validation.

Метрики выше получены на разбиениях по людям. Модели на всех данных отдельно на новых людях ещё не оценивались; порог отказа для них не настроен. Значение `confidence` — оценка классификатора, её калибровка не проверена. Имена категорий по-прежнему требуют окончательной сверки ID.

Применение без обучения к одному повторению в формате EC3D — массиву `.npy` формы `(кадры, 25, 3)`:

```bash
python scripts/predict_squat.py path/to/repetition.npy
```

Команда пока принимает подготовленный 3D-скелет; подача RGB-видео и координат MediaPipe требует отдельной проверки совместимости. При сохранении скрипт загружает каждый файл обратно и сверяет предсказания с моделью в памяти. Каталог `models/` исключён из Git; другой путь задаётся через `--models-dir`. Загружайте только доверенные файлы `.joblib`: этот формат может выполнять код при чтении.
