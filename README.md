# Оценка техники приседаний по видео

Рабочая цель: по короткому видео одного приседания определять тип ошибки и сообщать, когда данных для оценки недостаточно.

**Решение от 04.11.2026:** первый прототип строим на EC3D; срок — неделя, ресурсы — RTX 2060 6 ГБ или Colab. Доступа к FLEX/MyoMechanix и Fitness-AQA пока нет. Научная гипотеза: учёт доступности суставов в информативной фазе уменьшает ложные замечания при контролируемой доле отказов. Новизна и эффект пока не доказаны.

## Что уже работает

Загрузка проверенной версии EC3D, сборка повторений из кадров, аудит и два обучаемых baseline. В эксперимент вошли **132 приседания четырёх участников**. Все кадры одного человека остаются в одной части данных.

| Подход | Macro-F1: правильно / ошибка | Macro-F1: пять меток |
|---|---:|---:|
| Постоянный ответ | 0,407 ± 0,010 | 0,095 ± 0,007 |
| Геометрия + логистическая регрессия | 0,786 ± 0,233 | 0,622 ± 0,035 |
| Координаты + логистическая регрессия | 0,622 ± 0,221 | 0,432 ± 0,169 |

Среднее и стандартное отклонение посчитаны по четырём тестовым участникам. Классификатор пока проверен **на подготовленных 3D-скелетах EC3D**. Извлечение позы из обычного видео и перенос между системами суставов ещё предстоит реализовать и проверить.

## Запуск

Python 3.10 или 3.11. Для этих baseline GPU не нужен. Команды выполняются из корня репозитория.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/download_ec3d.py
python scripts/ec3d_baseline.py
python -m unittest discover -s tests -v
```

В Colab достаточно установить зависимости и выполнить те же два скрипта Python. Загрузка использует конкретную версию репозитория авторов и проверяет SHA-256.

Артефакты находятся в `reports/ec3d_baseline/`: аудит, таблица повторений, разбиения, метрики, предсказания и матрицы ошибок. Новый опыт запускайте с `--output reports/<название>`, чтобы сохранить исходный результат. Сырые данные в `data/raw/` и окружение `.venv/` исключены из Git.
