# Оценка техники приседаний по видео

Учебный проект по компьютерному зрению: исследование оценки двух ошибок приседания по позе человека и подготовка статьи.

**Текущий этап:** поиск моделей на готовых позах завершён; дальше — собственные видео и существующий классификатор. Полный путь от камеры пока не проверен.

Начните с [передачи контекста в едином дневнике](experiments/README.md#handoff-current): там замысел пользователя, причины решений, завершённые гипотезы и следующий шаг. Инструкции для агента — [AGENTS.md](AGENTS.md).

## Текущая модель и вход

Основная модель — логистическая регрессия на 35 геометрических признаках. Три класса: корректно по выбранным критериям, колени внутрь, малая глубина. Модель оценивает одно заранее выделенное полное повторение MediaPipe **world**-поз формы `(кадры,33,4)`; RGB-видео и нормированные экранные координаты непосредственно на вход не подаются. Score не является откалиброванной вероятностью правильности, отказы ещё не настроены.

Веса: `models/rehab26_baseline/squat_geometry.joblib`. Это модель на всех обучающих людях; опубликованные метрики относятся к внешним разбиениям, а не к независимому тесту этих весов. Временная CNN исследована, но основной вариант не заменяет.

## Применение без обучения

Python 3.10/3.11, команды из корня репозитория:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/predict_rehab26.py path/to/repetition.npy
```

`models/`, `data/raw/` и `.venv/` исключены из Git. Для другого компьютера нужно отдельно передать доверенный файл весов; клонирование одних отчётов модель не переносит. Порядок передачи описан в дневнике. Геометрический классификатор работает без PyTorch.

## Воспроизведение и проверки

Повторять обучение для чтения репозитория или продолжения видеопути не требуется. При отдельной задаче воспроизведения временного опыта используются:

```bash
python -m pip install -r requirements-temporal.txt
python scripts/download_rehab26.py
python scripts/run_temporal_comparison.py
python -m unittest discover -s tests -v
```

Каждый запуск создаёт новый архив и сохраняет исходники/настройки/предсказания; прежние результаты и основная модель не подменяются. Синхронные внутренние проверки выполняются четырьмя процессами с одним CPU-потоком; `--inner-workers 1` включает последовательное исполнение. Проверка архива без обучения: `python scripts/experiment_log.py verify experiments/runs/<имя>`.

Историческая задача [EC3D](reports/ec3d_baseline/README.md) имеет другие классы и формат `(кадры,25,3)`; её модели и показатели не смешиваются с REHAB26.
