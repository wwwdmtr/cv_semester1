# REHAB26: согласованность предсказаний между ракурсами

Источник: `reports/rehab26_baseline/fold_predictions.csv`; анализируемый метод: `inner_selected`.
Скрипт использует готовые внешние предсказания и не переобучает модель.

## Главный результат

Для **164 из 388** физических приседаний (**42.3%**) синхронные камеры дали разные категории. Все ракурсы одновременно распознаны правильно для **210 повторов (54.1%)**; ни один ракурс не дал правильную категорию для **20 повторов (5.2%)**.

Это показывает чувствительность текущего baseline к наблюдаемому ракурсу, но не доказывает причину расхождений: в наборе только пять людей, а camera ID и фактический угол съёмки не всегда означают одно и то же.

## Интерпретация и следующий шаг

- Ответ модели заметно меняется для одного и того же движения при смене камеры.
- Сравнение по camera ID нужно отделять от сравнения по фактическому диапазону угла.
- Следующий эксперимент должен проверить, объясняют ли visibility нужных суставов и нижняя фаза эти расхождения лучше, чем одна уверенность классификатора.
- До проверки на новых людях и независимых данных результат остаётся исследовательским.
