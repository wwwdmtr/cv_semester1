## Финальный вывод проекта

1. Честный однокамерный baseline на новом человеке воспроизведён, но не достиг двух инженерных ориентиров: ложные замечания составили 21,1% при требовании не более 20%, обнаружение ошибок — 74,2% при требовании не менее 80%.
2. Основная гипотеза отклонена: visibility нужных суставов не превзошла уверенность модели как признак ненадёжного замечания.
3. Лучший описательный вариант — усреднение трёх синхронных камер: Macro-F1 0,749, ложные замечания 14,9%, обнаружение ошибок 75,3%. Это исследовательский ориентир, а не готовый однокамерный режим.
4. Фиксированные 2D-признаки и аугментации не дали приемлемого компромисса и не входят в финальный pipeline.
5. Автоматические рекомендации пользователю не разрешаются. Для публикационного вывода нужны новые люди или независимый согласованный набор, исходные RGB-видео и заранее зафиксированная повторная проверка.

Таким образом, недельный план завершён как воспроизводимое исследование с полезным baseline, многоракурсным наблюдением и честным отрицательным результатом, но не как готовый продукт или доказанная публикационная новизна.

## Команды контрольного повторения

Два baseline запускаются с одинаковым `seed=0` в разные пустые каталоги. После этого выполняется проверка:

```bash
python scripts/verify_final_release.py \
  --control <первый-каталог>/report \
  --repeat-control <второй-каталог>/report
python -m unittest discover -s tests -v
```

Машинная версия проверки: [final_verification.json](final_verification.json).
